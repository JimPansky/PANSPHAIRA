## Actual product entry

`src/pan526/local-runtime-adapter.mjs` exposes `createLocalRuntimeAdapterV1` to a trusted local owner. All seven options are closed and required: explicit `optIn`, absolute real `sourceRoot`, exact40-character `sourceCommit` and `sourceTree`, immutable `imageDigest`, isolated `instanceId`, and positive `expectedGeneration`. Main/latest, aliases, unknown options, role declarations and non-loopback bindings deny before dispatch. The selected product source must be clean and its actual Git commit/tree must match; the selected image and owned five-container namespace are independently inspected.

The adapter reads actual Node architecture/version, product version and policy generation from the running native container. It separately creates Desired and Observed states with opaque logical secret-slot references. Raw secret values never enter identity or receipts. Readiness performs the existing protected business order read, compares an independently fixture-derived expected value to the actual provider result, and observes loopback/privilege/socket/resource-owner boundaries. ActualHTTP200 with a changed native quantity returns NOT_READY; restoring that same native quantity returns READY. No liveness result opens a route.

Lifecycle jobs bind audience, tenant, instance, component, generation, identity digest, desired-state digest, issuance and bounded deadline. Only an already authorized local operator can invoke this API. Native start/stop/restart applies only to the inspected owned PanSphaira container. The persistent local job store records an ambiguous outcome before dispatch; interrupted dispatch remains `outcome_unknown` with no auto-retry. Exact job reuse returns retained observations rather than a second effect; collisions deny. Definitive success/failure receipts require the corresponding typed observation and closed reason combination.

`node scripts/read-pan526-portable-local-runtime-v1.mjs --opt-in-local-owner --source-root <installed-exact-local-source> --instance-id <owned-isolated-instance> --source-commit <qualified40hex> --source-tree <qualified40hex-tree> --image-digest <sha256-qualified-image-id> --generation 1` is the bounded read-only local reader. Optional `--bounded-read-load` performs20 additional protected readbacks. Unknown, duplicate or missing flags deny with sanitized HELD output. This is not a remote endpoint, generic Docker administrator, installer privilege bypass or authorization shortcut.

Run the local source/denial suite with `npm run pan526:test`. Actual native tests require an existing explicitly isolated installed profile supplied through `PAN526_NATIVE_PROFILE` and run with `npm run pan526:native:test`; missing native setup fails, it is not a synthetic PASS or SKIP. The mandatory ordinary source suite does not silently launch Docker or acquire local-owner permission.
